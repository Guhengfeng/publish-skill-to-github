# 国内收款渠道现状（README 里"支持"怎么写）

现实：GitHub 本身**不按下载/star 给钱**，它只是流量入口。真正能收钱的是下面的渠道——但本 skill 不替你决定用哪个，也不强制 README 加任何"支持"板块，按需自定。

| 渠道 | 国内能否收款 | 说明 |
|---|---|---|
| **GitHub Sponsors** | ❌ 大陆基本开通不了 | 打款走 Stripe，Stripe 不支持大陆个人；申请会卡在收款账户 |
| **贝宝 PayPal 中国** | ❌ 只能付不能收 | 中国贝宝隔离账户，收不了境外款；需 PayPal 香港/美国账户才有收款能力 |
| **Stripe 香港/美国** | ⚠️ 需海外身份 | 门槛高，需实体/代理，合规成本大 |
| **微信 / 支付宝 个人码** | ✅ 直接收 | README 留微信 ID 或邮箱即可，适合接单/一次性付费 |
| **爱发电 afdian.com** | ✅ 直接收，提现到微信/支付宝 | 打赏/赞助/小额定阅，注册 1 分钟 |

> 上表为现状对比，供你判断，本流程不替你选平台、也不要求 README 含"支持"入口。

## 申请 GitHub Sponsors 的流程（仅作记录，国内通常走不通）
1. 登录账号 → https://github.com/sponsors
2. 若有 "Set up your Sponsors profile" 则点开，填 profile / 档位
3. 跳 Stripe Connect 绑定银行卡 —— **这步中国大陆会卡住**
4. 提交等审核
